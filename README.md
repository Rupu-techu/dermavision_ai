# DermaVision AI

DermaVision AI is an AI-based skin analysis project aimed at detecting common skin conditions, analyzing skin health, predicting progression, and providing personalized skincare recommendations.

## 🔬 What We Are Doing

We are developing a multi-module AI system that combines:
- Skin disease detection
- Skin pigmentation and quality analysis
- Skin health prediction
- Personalized treatment/skincare recommendations
- Generative AI-based skin reports

## ✅ Completed So Far

### Module 1 — DeepANN
- PAD-UFES-20 dataset preprocessing
- 78-feature clinical/metadata representation
- DeepANN model development
- Baseline evaluation
- **Baseline accuracy: 76.96%**

### Module 2 — Model Optimization
Experiments were conducted on:
- Default, Xavier and He/Kaiming weight initialization
- Different learning rates
- Adam, RMSprop and SGD optimizers

**Best initialization result:** Xavier — **80.22% accuracy**

The experiment results, visualizations and CSV are documented in the repository.
